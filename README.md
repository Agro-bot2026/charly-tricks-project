## Estructura
- web/ : sitio web estatico (index.html, privacidad.html, sitemap.xml, robots.txt)
- email-bot/ : bot de respuesta automatica de emails (IMAP + DeepSeek + Resend)
- reviews-api/ : API de resenas con IA (Flask + SQLite + DeepSeek)
- branding/ : logos e imagenes de marca
- nginx/ : configuracion del servidor

## Stack
Frontend: HTML/CSS/JS. Backend: Python, Flask. DB: SQLite. IA: DeepSeek.
Email: Spacemail + Resend. Infra: Nginx, Cloudflare, PM2. Hosting: VPS InterServer.
